# Cosmic Lens — NASA WEB Explorer

A clean, web-based explorer that fetches and displays NASA's Astronomy Picture of the Day (APOD).

## What it does

* Fetches NASA's Astronomy Picture of the Day automatically when you open the page.
* Allows you to pick any past date using the date selector to view previous pictures and their explanations.
* Displays detailed astronomical context, titles, dates, and explanations provided directly by NASA.

## Built With

* avaScript
* HTML
* CSS
* Vite
* NASA APOD API

## How to run it locally

1. Clone this repository to your local machine:
   git clone https://github.com/ankitdey2682010-a11y/Pulse_web.git

2. Navigate into the project directory:
   cd Pulse_web

3. Install the dependencies:
   npm install

4. Start the development server:
   npm run dev

5. Open the local address provided in your terminal (usually http://localhost:5173) in your web browser.

## How to build for production

npm run build
npm run preview
